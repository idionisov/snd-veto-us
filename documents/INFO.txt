The parameters are stored in the file as [t_0, alpha, beta, QDC_0, gamma] and are applied using function 4.1.9 in my thesis. Simona: I managed to get a better TW description post working with SND, the function changed a little, and in thesis section 4.3.4 I do a min NLL optimisation to find an error-floor.  

The experiment needs three different sets of fine alignment parameters depending on the run number, the conditions for which alignment parameters to apply are in table 3.6 of my thesis. Also, I've just put the DS alignment parameters in the public folder at the moment. These parameters align the US muon system SiPMs with the DS muon system. I also have parameters to align the US with the SF timing which I will put into the public directory soon. Will you need these soon? 

These alignment parameters are measured such that they align a US SiPM with my 'DS reference time' which is defined in equation 4.1.1. The function for measuring this time is here and determined in the code block: ```if mode=='tds0'```.

There are also the effective signal speeds, the effective signal speed doesn't change much throughout runs (see section 4.3.2 of my thesis) so in I've put in public/ the file public/run005999_cscintvalues.json which contain: [the effective signal speed, the uncertainty from the fit, the systematic uncertainty] the last of which I describe in that section of my thesis. The effective signal speed is used with the extrapolated DS track position to account for the signal photon time-of-flight in the scintillator to the SiPM. The code for correcting for this time-of-flight is here but there are a few steps that go into that. 

If you clone my fork here.  The following won't work out the box without changing some file paths etc. from mine to yours, but it's a good indication of how the code is run:
python -i $SNDSW_ROOT/shipLHC/scripts/run_TimeWalk.py -p $1 -r $2 -s $3 -n $4 --m $mode --XT --referencesystem $referencesystem
Where 
1=/eos/experiment/sndlhc/convertedData/physics/2023/ - path to the offline format data
2=5999 - run number
3=0 - start event number
4=10000 - number of events
mode=systemalignment - the analysis mode
referencesystem=3 - 3 for the DS reference time, 1 for the SF reference time, so the code knows what alignment params to use.
